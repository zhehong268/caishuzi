# 猜数字游戏 (Guess Number)

一个用 Python 编写的简单命令行猜数字小游戏。程序会随机生成一个 1~100 之间的整数，玩家通过不断猜测来找到正确答案，猜中后会统计总共猜了多少次。

## 功能特点

- 随机生成 1~100 之间的整数作为答案
- 对输入进行校验，非整数或超出范围的输入不会被计入猜测次数
- 每次猜测后给出“太大”或“太小”的提示
- 猜中后显示正确答案和总猜测次数
- 代码结构清晰，适合 Python 初学者阅读和学习

## 环境要求

- Python 3.x
- 无需安装第三方库，仅使用 Python 标准库 `random`

## 如何运行

1. 将游戏代码保存为 `caishuzi.py`（注意：文件编码建议使用 **UTF-8**，避免中文乱码）。
2. 在终端或命令行中进入文件所在目录。
3. 运行以下命令：

```bash
python caishuzi.py
按照提示输入你猜的数字，直到猜中为止。

游戏规则
程序随机生成一个 1 到 100 之间的整数。

玩家每次输入一个整数。

如果输入的不是整数，或数字不在 1~100 范围内，程序会提示重新输入，且不计入猜测次数。

如果猜的数字比答案小，提示“太小了，再大一点！”。

如果猜的数字比答案大，提示“太大了，再小一点！”。

猜中后，程序会显示答案以及总共猜测的次数，然后结束游戏。
```
